# Mutirão no Bem

Sistema interno para acompanhamento de pré-inscrições, triagem, matrículas, anamneses, rematrículas e turmas do Educandário Mutirão no Bem.

## Tecnologias

- PHP 8.3 e Laravel
- Blade, Tailwind CSS e Alpine.js
- Vite

## Instalação

```bash
composer run setup
```

## Desenvolvimento

```bash
composer run dev
```

## Testes

```bash
composer test
```
